Put your photos in this folder.

1. Your portrait: save it as  arun.jpg  (roughly 3:4, portrait).
2. Hobby photos: any file names you like, e.g.  golf-1.jpg, camping-1.jpg
   Then list them in the CONTENT block at the top of index.html, e.g.

   { object: "golfball", name: "Golf", note: "Handicap: 2.7",
     photos: [
       { src: "photos/golf-1.jpg", caption: "Plainfield, summer 2025" },
       { src: "photos/golf-2.jpg", caption: "" }
     ] },

Keep each photo under about 500 KB so the site stays fast (1600 px wide is plenty).
